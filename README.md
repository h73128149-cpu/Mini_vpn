# HesVPN Mini App

Static Telegram Mini App UI (Persian, RTL, responsive dark/red design).

## Publish with GitHub Pages
1. Publish the contents of this `mini-app` folder using GitHub Pages.
2. Set `WEB_APP_URL` to the published HTTPS URL in Render.
3. The current frontend sends `web_app_data` payloads for actions. The bot backend must handle these payloads before purchases/actions will work end-to-end. This package currently includes the visual frontend and existing bot flows; Mini App data actions are not yet wired into the backend.

Do not publish a real bot token in a public repository.
